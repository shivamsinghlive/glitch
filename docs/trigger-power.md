# Hot-flash trigger test: power and calibration

Generated by `scripts/trigger_power_table.ts` (`pnpm power:triggers`). Deterministic (seeded). Method in `client/src/lib/menopause.ts`:
per-trigger Poisson rate ratio with Wald 95% CI on log-RR, one-sided permutation test, Benjamini–Hochberg across tested triggers;
a trigger is flagged only if q < 0.10 **and** the CI lower bound > 1. Triggers need ≥5 days with and ≥5 without.

## 3. False positives under the null (full procedure)

No trigger has any effect (RR = 1). Each simulated user has 6 candidate triggers, each present on a random ~30% of days; full procedure with 2000 permutations + BH + CI rule. 500 simulated users per row.
**Family-wise** = share of users shown at least one (false) trigger; **per trigger** = share of tested triggers falsely flagged.
Overdispersed rows use negative-binomial counts (variance = μ + μ²/2), closer to real symptom diaries than Poisson.

## Caveats

- Simulations assume days are independent; real symptoms carry over between days (autocorrelation), which the permutation test does not model.
- Trigger days are assumed to be logged accurately; missed logs dilute the effect and lower power.
- A flagged trigger is an association in one person's logs, not proof of cause.
